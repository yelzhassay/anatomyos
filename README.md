# AnatomyOS Остеология (MVP)

Веб-приложение: интерактивный 3D-скелет человека в браузере (компьютер и телефон).

## Что входит
- 203 модели костей (череп, позвоночник, грудная клетка, конечности, кисть, стопа).
- Атлас: выбор кости кликом или из списка, поиск (рус/лат/англ), название по-русски и по-латыни, сторона, краткое описание, скрыть/изолировать кость, виды спереди/сбоку/сзади.
- Тест на 10 вопросов: «Назови кость» (4 варианта) и «Найди на модели» (клик), по всему скелету или по отделу.

## Уроки
Вкладка «Уроки»: курс из 8 тем (общая остеология, позвоночник, грудная клетка, верхняя конечность, кисть, нижняя конечность, стопа, череп).
- Лекция в каждой теме: видео или аудио на выбор студента. Пройденная лекция открывает следующую тему.
- Практическое занятие по шагам, каждый открывается после предыдущего: подготовительные ролики → видео занятия → тест на 3D-модели (10 вопросов, «Назови кость» и «Найди на модели») → оценка по шкале A–F (лучшая попытка).
- Просмотр засчитывается, когда проиграно не меньше 90% ролика (перемотка не считается). Для Google Drive и других встраиваемых ссылок студент отмечает просмотр сам.
- Прогресс и оценки хранятся в localStorage браузера студента (сервера пока нет).

### Как добавить ролики
Ссылки лежат в `lessons.json`, а редактируются в админке: `admin.html` на сайте (https://yelzhassay.github.io/anatomyos/admin.html).
1. Загрузить видео на YouTube с доступом «По ссылке» (подходят также Google Drive и файлы из папки `media/`).
2. Открыть админку, войти по паролю, вставить ссылку в нужную тему и шаг, нажать «Опубликовать». Сайт обновится через несколько минут.
3. Проверить ролики можно на сайте с `?author` в адресе: в этом режиме замки сняты.

Первый вход на устройстве: админка попросит ключ GitHub (fine-grained token только на репозиторий `anatomyos` с правом Contents: Read and write) и пароль. Ключ хранится в браузере, зашифрованный паролем; админка записывает `lessons.json` в репозиторий через GitHub API, сервера нет. Когда появится собственный плеер, формат `lessons.json` останется тем же, поменяются только ссылки.

Пустой слот показывает заглушку и кнопку «Пропустить (демо)», чтобы путь можно было пройти до появления роликов.

## Файлы
- `index.html` — приложение (Three.js r147 с jsDelivr).
- `admin.html` — админка ссылок на ролики уроков.
- `lessons.json` — ссылки на ролики уроков; `media/` — видео и аудио файлы уроков.
- `bones-mesh.bin.gz` (сжатые бинарные данные), `bones_mesh.json` — упрощённые сетки (int16-квантование, ~260 тыс. треугольников, ~1,7 МБ).
- `tools/build.py` — сборка сеток из STL; `tools/bones2.txt` — список FMA-ID и английских названий.

## Пересборка
STL берутся из https://github.com/Kevin-Mattheus-Moerman/BodyParts3D (`assets/BodyParts3D_data/stl/<FMA-ID>.stl`) в папку `stl/`.
`pip install trimesh fast-simplification numpy`, затем `python3 tools/build.py <папка с bones2.txt и stl/> <выходная папка>`.
