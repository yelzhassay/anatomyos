Первая настройка

Админка публикует ссылки на ролики прямо на сайт. Для этого ей нужен ключ доступа GitHub. Его нужно создать один раз, это займёт пару минут.

  1. Откройте страницу создания ключа на GitHub (войдите в свой аккаунт, если попросит).
  2. Token name: напишите Админка AnatomyOS. Expiration: выберите самый долгий срок.
  3. Repository access: выберите Only select repositories и отметьте anatomyos.
  4. Permissions → Repository permissions → Contents: поставьте Read and write.
  5. Нажмите Generate token внизу и скопируйте ключ (начинается с github_pat_).

Ключ хранится только в этом браузере, зашифрованный вашим паролем. На другом компьютере или телефоне настройку нужно пройти ещё раз (можно тем же ключом).
