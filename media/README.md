# Видео и аудио уроков

Сюда можно класть файлы роликов (`.mp4`, `.webm`, `.mp3`, `.m4a`) и указывать их в `lessons.json` как `media/имя-файла.mp4`.

GitHub не принимает файлы больше 100 МБ, поэтому длинные ролики (15–30 минут) лучше выкладывать на YouTube (можно «доступ по ссылке») и вставлять ссылку.
